🎯 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

POST /api/auth/login
  └─ Login with Google ID token
  └─ Request:  { "idToken": "...", "accessToken": "...", "refreshToken": "..." }
  └─ Response: { "jwtToken": "...", "youtubeId": "...", "email": "...", ... }

GET /api/auth/me
  └─ Get current user info
  └─ Headers: Authorization: Bearer <jwt-token>
  └─ Response: { "id": 1, "youtubeId": "...", "email": "...", ... }

POST /api/auth/logout
  └─ Logout user (token invalidation)
  └─ Headers: Authorization: Bearer <jwt-token>
  └─ Response: 200 OK (empty)

POST /api/auth/validate
  └─ Check if JWT token is valid
  └─ Headers: Authorization: Bearer <jwt-token>
  └─ Response: true or false

🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Build Backend (2 minutes)
   ─────────────────────
   cd backend
   ./gradlew build -x test
   # First build downloads ~200MB dependencies

2. Start Backend (1 minute)
   ──────────────
   ./gradlew bootRun
   # Server starts on http://localhost:8080

3. Verify Running (1 minute)
   ─────────────────
   curl http://localhost:8080/h2-console
   # Should return H2 console HTML

4. Get Credentials (5 minutes)
   ──────────────────
   • Go to https://console.cloud.google.com
   • Create project → Enable YouTube API → Create OAuth 2.0 credentials
   • Copy Client ID to application.properties

5. Generate JWT Secret (1 minute)
   ──────────────────────
   # Add to application.properties
   ytlearner.jwt.secret=<256-bit-random-secret>
